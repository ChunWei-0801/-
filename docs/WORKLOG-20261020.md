## 免費模型方案

採裝置端開源 Qwen 模型與 WebLLM；模型由使用者明確啟動後下載到瀏覽器，不啟用付費推論 API，也不設定 OpenAI API 金鑰。首次需要約 290 MB 模型下載及支援 WebGPU 的裝置；不支援的裝置須清楚提示。模型未實際產生回覆前，不將 OCR、規則解析、資料摘要或測試替身標成 LLM 成功。

獨立試用入口規劃為 `#/ai`，既有手動記帳與八項生活功能保留。LLM 支援多筆文字／收據 OCR 記帳草稿、受權限控管的帳務問答、儲蓄教練／月報及教學文件檢索生成。數字由後端精確計算，模型草稿須由使用者核對確認才寫入，模型不直接執行 SQL 或修改資料。
