# 長期免費使用原則

2026-10-24使用者選擇：**保留線上家庭共用，使用免費額度；若服務到期或改收費就搬家。**

這是後續變更的費用限制，不是對第三方永久免費政策的保證。不自行開通付費方案、付費AI API或按量付費備援；免費額度不足時應如實說明暫停或限制，另找符合需求的免費替代服務，不靜默切到付費。

## 現況

- v181部署到現有Render服務；API已確認web plan為free，autoDeploy為no。本次未新增主機、資料庫、付費API或任何付費升級。
- render.yaml的web與PostgreSQL均指定free；但本次資料庫清單API回傳403，因此**未驗證實際資料庫方案、到期日與帳號Billing狀態**。免費設定檔不能當成帳單為零的證明。
- 記帳LLM在使用者裝置執行；農曆資料與時鐘在網站程式內。這些新功能沒有按次付費API。
- 手機版本是加入主畫面的線上PWA，沒有申請App Store或Google Play開發者帳號、沒有上架費用。網頁開啟時提醒及ICS匯出不使用付費推播。
- 郵件寄送、資料庫、網路傳輸與異地備份仍依各供應商免費額度及政策；使用者帳號的付款與超額設定須以各控制台為準。程式本身無法承諾供應商永不改價或保證帳號不被收取其他既有服務費用。

## 到期或搬移

1. 先確認來源目前的免費額度、到期日與備份時間，不能等資料刪除才安排。不要為延長免費期而輪流開帳號規避供應商政策。
2. 先備份最新資料與照片，將密文及金鑰分開保存。已驗證的2026-10-23 21:57臺灣時間快照不是自動持續備份；新行事曆等之後資料不在舊快照內。
3. 在另一個明確免費且容量足夠的全新資料庫還原，核對資料與照片雜湊、遷移、登入、權限及新舊行事曆。提供切換與回退方式，再依授權切換正式服務。不能覆寫唯一資料庫或把暫存磁碟當長期備份。
4. 確認新服務正常後才處理舊服務；保留復原副本。需要修改服務商、OAuth或郵件設定時照實列出變更。

本次沒有替換正式資料庫，沒有建立自動搬家、額度監控或自動備份排程。要持續免費，仍需在供應商政策或用量變動時檢查及處理；不能保證同一免費平台永久可用。
