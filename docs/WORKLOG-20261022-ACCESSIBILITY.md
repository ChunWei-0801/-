- 報表總額取完整授權資料、明細另分頁；下載真正的 `.xlsx`／`.docx`，超過 10,000 筆或文字上限時拒絕，要求縮小範圍，不下載偷偷截短的檔案。搜尋地點指已記錄的店家、活動或備註文字，不能推測沒有記錄的位置。
