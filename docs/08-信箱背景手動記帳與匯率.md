# 新功能操作：信箱驗證、登入背景、實際金額與國際匯率

桌面及手機使用同一份響應式介面。先依根目錄 README 啟動完整前後端；
本機可用 `python run.py --sqlite`，有 Docker 時使用 `python run.py`。
以下說明對應正式功能；本機開發驗證連結會明示「沒有寄出郵件」。

## 1. 驗證信箱（Email verification）

1. 註冊自己的帳號，或在登入頁選「驗證信箱」，填入註冊用的 email。
2. 申請驗證信。正式環境請到收件匣或垃圾信件匣開啟「驗證信箱」連結。
3. 連結在 30 分鐘內有效且只能使用一次。過期時重新申請，重新寄發後舊連結失效。
4. 驗證成功後登入；個人資料會反映已驗證。

**開發展示：**沒有 Brevo 設定時，畫面明確標示未寄信，並提供開發用驗證連結。
它只在 development 提供，正式環境不會回傳這種連結。
正式註冊不發登入權杖，未驗證的帳號不能以密碼或續期接口取得財務資料。

**正式寄信設定：**在自己的服務平台安全設定 `BREVO_API_KEY`、Brevo 已驗證的
`MAIL_FROM`，並將 `APP_BASE_URL` 設為自己的公開前端網址。
Blueprint 預設 `REQUIRE_EMAIL_VERIFICATION=true`。缺寄件設定時，登入頁會顯示服務未啟用，
不能用本機示範連結代替正式信件。實際 Brevo 寄送目前尚未驗證。

回應使用通用訊息，避免公開列出哪個信箱已存在；申請與重寄有冷卻及限次。
驗證連結的 token 只以雜湊保存；介面處理連結時會清除網址中的 token。

## 2. 自由登入背景（Login background）

在登入或註冊頁展開「登入背景」：

| 選項 | 英文名稱 | 內容 |
|---|---|---|
| 紙上晨光 | Paper Sunrise | 柔暖光暈與紙紋 |
| 森林微風 | Forest Breeze | 綠意漸層與自然光影 |
| 星空暮色 | Starry Dusk | 靛藍夜色與星點 |
| 自己的照片 | Your Photo | 選擇檔案、相簿或拍照 |

選自己的照片後，可調整：

- **填滿 Cover**：鋪滿畫面，部分圖片可能被裁切。
- **完整顯示 Contain**：保持比例，全圖可見。
- **重複鋪排 Tile**：原尺寸重複形成圖樣。
- **原始尺寸 Actual size**：依瀏覽器解讀的圖片尺寸呈現。
- 左右／上下位置、亮度 Brightness、模糊 Blur、主題色遮罩 Overlay。

**照片不設應用程式的檔案大小上限。** 原始檔以 IndexedDB Blob 存在目前裝置的
瀏覽器，沒有改成 localStorage 字串，也不會上傳到後端。
實際容量與可解碼的格式取決於裝置、記憶體及瀏覽器空間；儲存失敗時可暫時使用並重試保存。
已驗證 8,808,655 bytes 的 PNG 原檔保存與重載恢復。

手機可選相簿或用「拍照」入口；同樣可以調整所有滑桿。
「恢復預設」會清除這裡的照片和背景偏好，不清除帳務資料。
在另一台裝置需重新選擇照片；登入後的系統主題另外設定。

## 3. 獨立填入實際金額（Manual entry）

1. 登入後點「手動輸入實際金額」，或從明細頁的手動記帳入口開啟。
2. 填寫日期、實際金額、收入／支出、分類、帳本與備註。
3. 金額必須大於0，最多依帳本的分位記錄。以你的付款明細或銀行實際扣款為準。
4. 按確認新增，再於明細與統計核對。

這條流程不呼叫 AI，也不要求先輸入一段文字。AI 解析與匯率試算都是可選輔助；
手動填寫的實際金額由你確認。確認前不寫入資料庫，新增後來源為 `manual`。

## 4. 換算匯率（Currency Converter）

1. 進入「國際匯率換算」，填入原始金額。
2. 選擇來源與目標幣別；可搜尋代碼、中文或英文名稱，例如 TWD、新臺幣、Japanese Yen。
3. 按「換算金額」。核對結果、來源與資料更新日期；用「互換」切換方向。
4. 若要入帳，把目標選為 TWD，按「帶入手動記帳」。
5. 介面預填換算金額與備註。你可以改成**實際扣款金額**，再選日期、收支、分類、帳本並確認。

本次來源可取得153種法定貨幣，包含 USD／TWD／JPY／EUR／GBP／CNY／KRW／HKD／THB／VND。
後端使用 Decimal（十進位）換算，依目標幣別的小數位處理，例如日圓0位、美元2位、科威特第納爾3位。
零金額可試算，不能寫成一筆0元帳；負值、非數字與不支援的幣別會被拒絕。

**資料來源：**主要來源為 ExchangeRate-API Open Access，備援為 currency-api 每日彙整。
目前雲端代理拒絕主要來源，已以真實 CDN 每日資料完成驗證。
畫面會明示備援、來源提供的資料日期與過期狀態；不把每日行情說成銀行即時成交價。
匯率有快取與刷新間隔；完全沒有可用行情時回報不可用，不硬填假匯率。

例如資料日期2026-10-14的一次實測：100 USD → 3218.08 TWD。
這是有日期的實測例子，不保證未來仍得到同樣數字。
金融機構可能另含買賣差價與手續費，因此填入後仍可修改為實際扣款。

**記帳本位幣目前仍為 TWD。** 試算頁可換算不同國家貨幣，帶入帳本時轉成新臺幣，
備註保留原幣金額、匯率與資料日期。這讓海外交易可納入既有統計，不會把不同幣別直接相加。

## 5. 發表示範順序

1. 手機或桌面登入頁切換三種背景，選自己的照片並調整顯示，重新整理看偏好保留。
2. 用新的展示帳號申請信箱驗證，說明目前是開發連結或真實郵件，再完成驗證。
3. 先手動新增一筆真實金額，說明不依賴 AI。
4. 試算一筆外幣交易，核對來源日期，帶入手動欄位，修改成實際扣款後確認。
5. 在明細與統計核對小數金額，再說明海外換算與本位幣的關係。
