# 免費裝置端 LLM 與試用驗收

## 可測試入口與費用範圍

- `/ai-test.html`：不需帳號的真實模型試跑頁。明確啟動後載入模型，可輸入文字或執行兩筆合成範例欄位比對；不寄信、不讀寫帳務。
- `/#/ai`：登入後的完整 AI 試用頁；總覽常用功能與設定均有入口。功能仍採明確啟動及確認寫入，供使用者先測試再決定是否持續使用。
- 模型推論在使用者裝置執行，沒有付費 API、API 金鑰、雲端推論帳單或自動付費備援。初次模型下載約 290 MB，仍使用使用者自己的網路流量、電力與裝置資源。
- 需要安全來源 HTTPS（本機 localhost 例外）、WebGPU 及約 1 GB 可用 GPU 記憶體。沒有通過裝置檢查時明確拒絕載入；手動記帳與既有報表保留。不保證所有手機都能運行模型。
- WebLLM 可能快取模型檔；離開 AI 頁、登出或切換帳號／家庭權限上下文時清除本次輸入、查詢資料及模型工作階段，不將對話或帳務快照寫入瀏覽器儲存空間。明確確認入帳的原始輸入會和解析紀錄一起保存至帳號資料庫，畫面在確認前提示。

## 模型與資料流程

使用 [WebLLM 0.2.86](https://webllm.mlc.ai/docs/user/get_started.html)，在同來源的 module worker 內執行開源 `Qwen2.5-0.5B-Instruct-q4f16_1-MLC`。若 GPU 沒有 shader-f16，改用同一個小型模型的 q4f32 版本；兩者都需要 WebGPU。約 945／1060 MB 是官方模型登記的 GPU 記憶體估計，不是各裝置實測結果。模型來源與編譯資源由官方 WebLLM 登記提供，第一次下載需要外部資源連線。

文字記帳：使用者文字 → 模型 JSON 結構化草稿 → 獨立日期／金額／幣別／分類驗證 → 可編輯欄位 → 明確選擇帳本與確認 → 既有後端記帳驗證及交易。多筆使用既有批次確認接口，全部通過才一次寫入。模型沒有資料庫寫入權限。

照片記帳：相機／照片 → Tesseract.js 7 本機 OCR → 可修改辨識文字 → 同一文字模型產生草稿。這是 OCR 加文字 LLM 的兩階段流程，沒有將文字模型宣稱為視覺語言模型。圖片只有在使用者確認附加後才透過既有私有照片接口保存；上傳失敗不再重複新增記帳。

帳務問答／儲蓄教練／月報：使用者明確選擇月份與個人／家庭範圍 → 受權限控制的唯讀工具 → 後端 Decimal 精確統計及具識別碼的來源 → 模型解釋 → 來源與精確事實分開展示。這是受控查詢工具輔助生成，沒有宣稱小型 Qwen 支援原生 function calling。模型不能自選使用者、執行 SQL 或擴張家庭權限；僅有摘要權限的監管關係不提供單筆交易內容。

操作問答：固定的本機雙語教學／規則語料 → BM25 檢索相關段落 → 附來源的模型回答。這是檢索增強生成（RAG），不需要額外付費向量資料庫；未經測試不宣稱微調或嵌入模型。對話問題留在裝置，檢索接口只接收操作主題查詢。語料目前為繁中／英文，其他介面語言由本機模型產生回覆。

## 正確性與測量

- 金額、差額、分類總額與儲蓄缺口由伺服器計算，回傳精確十進位字串；交易分頁不得冒充完整總額。
- 帳務與教學來源以識別碼引用；輸入、收據、名稱與段落均當作資料處理。回覆若引用不存在的來源、引入證據沒有的數值、截斷或空白，須顯示錯誤，不呈現為成功回答。
- 引用與數值檢查只是防護，不等同於證明所有語意正確。使用者仍須核對來源；小型模型可能誤解分類、時間或敘述。
- 試用頁記錄實際模型名稱、延遲、輸入／輸出 token（runtime 有提供時）、來源數及使用者核對結果；下載的評估紀錄不包含原始輸入、照片、帳務或回答。
- 公開測試頁的兩筆合成範例只有在實際生成後才顯示欄位比對結果；不能把兩筆結果外推為整體模型準確率。

## 驗收證據的區分

後端權限／精確數字、本機瀏覽器 UI／API 整合、語言切換、模型套件實際匯入、OCR 與真實 LLM 推論需各自記錄。假 worker 或固定生成回覆只能測介面契約，不列入模型品質評估。

使用者先前回覆「成功產生記帳草稿」，但隨後以實際畫面更正：在已部署的 `/ai-test.html` 輸入「今天早餐65元，午餐120元。」後，畫面顯示 `The model did not produce usable draft items.`，測量仍為尚未完成。以這項較新的失敗證據為目前狀態，不能勾選真實 LLM 草稿生成驗收成功，也不能填入模型準確率或把先前簡短回覆當成通過證據。worker 修復進行中，修正後須重新部署並由使用者裝置重測。

目前 managed cloud 沒有可用 WebGPU，且模型下載主機未在執行中政策內，尚不能在這台機器完成真實模型生成。最新執行中環境 revision 748 亦沒有正式網站或資料庫目的地權限。雲端契約測試、模型套件匯入與使用者裝置端的生成結果須分開記錄。正式網站／信箱驗證及正式 PostgreSQL 備份仍依 `PRODUCTION-ACCEPTANCE.md` 分別驗收。

## 課程展示建議

使用未出現在提示範例的測試集評估日期、金額、幣別、分類及多筆切分；比較有／無檢索來源的回答支持率，記錄幻覺與拒答；展示跨家庭越權被後端拒絕，以及使用者修正草稿後才入帳。另提供真實裝置的模型載入時間、生成時間和記憶體需求觀測。這些證據可以說明免費開源模型的能力、成本及限制。

2026-10-20 的修正使用非空 few-shot 格式示範、動態分類／幣別 JSON 語法約束及至多一次真正模型重試；不以規則產生的交易替代失敗模型。失敗原始回覆與量測只留在頁面記憶體，支援六語錯誤說明並和成功紀錄分開。控制程式與 worker 同用資源版本 168。此修正仍須在使用者裝置重測，不能把 38 項介面／worker／API 契約檢查當作模型準確率。
