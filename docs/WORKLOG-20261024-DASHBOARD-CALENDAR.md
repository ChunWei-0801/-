# 2026-10-24 常用功能、浮動時鐘與私人行事曆

本次依使用者指定，預設為「所有登入頁面的浮動時鐘，可拖曳位置」。沿用現有免費服務，未啟用付費 API、語音、背景推播或外部行事曆帳號。

## 使用方式

- 儀表板平常只有「排列位置」。進入後出現「顯示/隱藏」，再打開勾選清單；「套用選擇」先保留在編輯草稿，外層「完成」一起儲存排序和顯隱。「取消」恢復原設定。全部隱藏仍可重新開啟編輯。
- 常用功能用獨立淺色卡片、大圖示及可換行名稱，手機兩欄、平板三欄、寬螢幕四欄。直接拖曳、觸控長按及鍵盤排序仍可使用。
- 浮動時鐘預設180px，五種造型（數位／經典指針／翻頁數位／極簡／環形指針），可拖曳及以角落把手或滑桿調至130–320px。關閉後可在設定→生活工具→時鐘設定恢復。僅外觀與位置按帳號保存在目前瀏覽器；也可切換成儀表板內顯示。
- 左側收支區補上日期、當月進度及實際記帳筆數，並縮短卡片，避免隨大量常用功能拉得過長。
- 抽菸加減只更新計數、肺色與歷史區，不重新建立肺部與整張卡片。肺部平緩呼吸；實際抽菸包數成功增加才咳三次，購買或減少包數不咳。尊重減少動態效果偏好。
- 常用新增「行事曆與班表」：私人行程、日期時間、備註、提前提醒；點日期再點早／午／晚班即可排班。同日換班會更新既有班別。可修改預設名稱、圖案及顏色，也可新增自訂標記。舊班表保留標記快照，不因改名或刪除標記改寫歷史。
- 農曆、節氣與農民曆宜忌可關閉。使用本地封裝 lunar-javascript 1.7.7（MIT）；民俗參考不代表官方國定假日。原套件會輸出 I18n，現已包在 FamBudgetLunar 命名空間，避免覆蓋網站的語系系統。
- 網頁開啟時檢查到期提醒，可自行授權裝置通知。關閉網站後若需要系統提醒，下載本月 .ics 匯入手機行事曆；檔案含提醒時間，實際通知由手機行事曆設定決定。未提供關閉網站後的伺服器背景推播。未指定時間的全天事項以帳號時區09:00計算提醒。
- 設定→安裝手機App：支援瀏覽器安裝的線上PWA。iPhone用Safari分享→加入主畫面；Android依瀏覽器安裝提示。未上架App Store／Google Play，也未提供離線記帳。Service worker不快取登入資料、API回應或帳務畫面。

## 資料與測試

新增0009遷移，僅建立calendar_markers與calendar_events及索引，不搬移舊交易或照片。應用架構34張表，含alembic_version為35張；先前已驗證的33表備份仍只代表當時快照。

後端完整測試1095通過；含跨帳號讀寫隔離、同日換班、快照保存、時區與夏令時間空檔、提醒確認與重新排程，以及完整遷移前後資料保存。API輸入、路由文件、資料表目錄與前端真實請求契約一併更新。

前端測試涵蓋顯隱暫存／完成／取消、帳號切換時禁止舊請求、拖曳、手機尺寸、時鐘逐秒不重建、農曆真值、班別一鍵提交、ICS注入及UTF-8折行、肺部DOM穩定與減少動畫。使用全站真實HTML、獨立SQLite資料庫及測試帳號檢查登入後手機／桌面呈現：無頁面程式錯誤、無橫向溢出。未寄信，未讀寫正式使用者資料。

新行事曆與時鐘介面以繁體中文為主；既有六語系不被套件覆蓋。本次不改已由使用者確認的v180十筆LLM流程，也不把來源規則結果當純模型準確率。
