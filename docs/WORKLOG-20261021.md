## 本輪修正

- 確認正常 HTML parser 在 DOMContentLoaded 前載入公開頁程式時，`I18n.ready` 尚未建立；`Promise.resolve(undefined)` 導致尚未載入的翻譯鍵寫入標題。初始 silent 載入後沒有重繪這些非宣告標題，因此保留代碼。
- 改為立即匯出同一個 deferred ready Promise，語言檔完成後才啟用模型操作。語言檔 URL 繼承資源版本，使用 no-cache 重新驗證，且合併同語言的同時請求。
- 標題使用可讀的 inline fallback 與 data-i18n；缺鍵／HTTP 失敗時仍保留可讀文字。宣告翻譯節點由單一 renderer 負責，避免 MutationObserver 雙重寫入循環。
- 模型拒絕錯誤加上固定 validation reason、field、rowIndex；不含使用者原文，由控制程式白名單傳遞。模型、prompt、schema 與接受／拒絕規則保持原有行為。
- 公開頁發生失敗時自動展開原始回覆，標題與紅框更明顯，方便使用者沿用現有結果回報。原始內容仍只在本頁記憶體，無自動上傳。
- GitHub 新增明確安裝 Playwright 1.57.0 與 Chromium 的 browser job，實際執行 parser 回歸，避免測試因缺瀏覽器而跳過。僅使用合成資料與模型替身，不下載模型或寄信。
