# 家庭記帳 FamBudget｜開始使用

在 GitHub 專案頁按 **Code → Download ZIP**，解壓縮後進入同時有 `run.py`、`backend`、`frontend` 的專案根目錄。

使用手冊：[36 頁 PowerPoint](fambudget-user-guide.pptx)、[PDF](fambudget-user-guide.pdf)。
PPT 檔案頁可按 **Download raw file** 下載；以下先帶你啟動與練習。

## 1. 先啟動（建議免 Docker 的 SQLite 模式）

需要 Python 3.12。第一次要有網路，以便啟動器安裝套件。

Windows PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe run.py --sqlite
```

macOS／Linux：

```bash
python3 -m venv .venv
./.venv/bin/python run.py --sqlite
```

等到終端機顯示就緒，再用瀏覽器開啟它印出的**完整前端網址**。不要直接雙擊 HTML。

日後啟動只需執行第二行；停止時在終端機按 `Ctrl+C`。SQLite 紀錄保存在 `backend/demo.db`，停止後仍保留。不要用 `--reset` 作為重啟方式，它會刪除開發資料庫。

## 3. 建議第一輪練習

建立自己的帳號，完成或略過初次設定，先用手動方式記收入 30,000 元；再記餐飲 55 元、交通 30 元、餐飲 45 元。金額都填正數，用「收入／支出」決定方向。

手動記帳第一次按「寫入這一筆」只進入確認狀態；核對按鈕的金額與分類，再按一次才保存。設定月存 5,000 元、餐飲預算 1,000 元後，應看到收入 30,000、支出 130、可花 24,870、餐飲預算使用 10%。請使用本月日期及沒有其他交易的新展示帳號。

也可先用本機開發帳號 `ledger@fambudget.tw`，開發密碼 `abcd1234`。這是公開示範帳號，只在本機開發啟動器建立；正式環境請自行註冊。既有展示資料可能讓統計不同。

## 4. 使用前要知道的狀態

- **信箱驗證：**本機未設定郵件服務時，畫面明示「開發展示連結，未寄出郵件」。正式寄信需要在服務平台設定 Brevo 金鑰、驗證寄件信箱與自己的 `APP_BASE_URL`；正式未驗證不能登入。本次沒有替你寄出真實驗證信。
- **文字解析：**尚未設定模型服務時，畫面會顯示「規則解析」；這不是微調模型成果。手動實際金額不需要 AI。
- **匯率：**可試算多國貨幣，入帳本位幣目前是 TWD。換算後可帶入手動記帳，依銀行實際扣款修改後再確認。每日參考匯率不是銀行即時成交價。
- **背景照片：**沒有應用程式檔案大小門檻，原檔只保存在目前裝置瀏覽器，不上傳後端。實際可用空間與格式仍受裝置、瀏覽器限制。
- **手機連線：**介面支援手機；電腦的 `localhost` 不是手機可直接開啟的網址。目前尚未建立公開站台，要讓其他裝置使用，請依專案 `docs/05-部署指南.md` 部署並驗收自己的 HTTPS 網址。

更多說明見專案根目錄 `README.md`、`docs/08-信箱背景手動記帳與匯率.md`，或啟動後在總覽點「操作教學」。
