記帳與家庭 Finance and family

English / 中文簡短解釋專題例子
Income收入流入的款項；金額為正數，方向由kind表示。打工賺1500，kind=income
Expense支出花出去的款項；不以負號取代收支欄位。早餐55，kind=expense
Net balance結餘同一範圍的收入減支出。1500 − 120 = 1380
Budget預算計畫中的花費上限，與已花金額比較。餐飲limit100、used120
Savings goal存款目標使用者想保留的款項；不是銀行存款證明。每月目標3000
Category分類將交易分組的固定或家庭自訂類別。餐飲、交通、薪資
Ledger / Group帳本／群組把相關交易放在共同容器；契約中group指帳本。旅遊帳本，不等同family
Settlement結算依帳本內收支整理分攤與差額。活動帳本結算
Family role家庭角色某人在這個家庭中的角色，與登入身分分開。parent（家長）、child（子女）
Guardianship監管關係指定誰可以查看谁的資料，與角色是不同規則。guardian（監管者）、ward（被監管者）
Allowance零用金家庭設定的零用金安排，不自動代表已收款。家長設定子女零用金
Read-only view唯讀檢視能查看資料，但不能透過此關係代改紀錄。查看被監管者交易

前後端 Web and API

English / 中文簡短解釋專題例子
Frontend前端瀏覽器裡的介面、輸入和互動。HTML、CSS、app.js
Backend後端伺服器端的規則、權限、儲存和計算。FastAPI app.main
API應用程式介面兩個程式交換資料的公開契約。/api/transactions
HTTP / RESTHTTP協定／REST架構風格HTTP傳請求與回應；REST常用資源路徑與HTTP動詞描述操作。GET查詢、POST建立、PATCH修改、DELETE刪除
Request / Response請求／回應呼叫端送的內容／服務端回的內容。送text，回items
Endpoint / Route端點／路由HTTP方法加路徑形成的服務入口。POST /api/nlp/parse-batch
Hash routing井號路由#後面的資訊由瀏覽器處理，不傳給伺服器。#/entry切換記帳頁
JSONJSON資料格式以物件、陣列、字串與數字傳遞資料。{"amount":55}
Adapter轉接器保留同一操作名稱，替換資料來源。api.js中的mock與http
Mock模擬實作以本機模擬資料來源練習介面；不證明真後端完成。瀏覽器localStorage模式
CORS跨來源資源共用瀏覽器依伺服器允許來源決定是否讓網頁讀取跨站回應。5174前端讀8000API
Same origin同源網址的協定、主機與埠號都相同。Render由同一服務提供前端和/api
Status codeHTTP狀態碼回應的類別與結果；成功碼不等於內容一定正確。200成功、201建立、401未認證、403拒絕、422驗證錯誤、503暫時不可用

資料與權限 Data and access

English / 中文簡短解釋專題例子
Schema資料結構定義資料有哪些欄位、型別與限制；API schema與資料表schema不必同名。API的date對應表的occurred_on
Validation驗證檢查輸入是否符合格式與業務條件。Pydantic驗請求；金額必須合理
ORM物件關聯映射用程式物件操作關聯式資料表。SQLAlchemy的Transaction model
Migration資料庫遷移以版本步驟更新資料表結構。alembic upgrade head
CRUD新增、讀取、修改、刪除Create、Read、Update、Delete四種基本資料操作。交易明細增刪改查
Transaction交易紀錄／資料庫交易記帳指一筆收支；資料庫指一組全做或不做的操作。transactions表；批次confirm的DB transaction
Atomicity / Rollback原子性／回滾一組操作全部成功才保留；失败就撤回整組。批次第3筆非法，前2筆也不留下
Decimal十進位精確數值依十進位表示金額，避免二進位浮點的小數誤差。資料庫NUMERIC、Python Decimal
Authentication認證確認「你是誰」。email、密碼與JWT登入
Authorization授權／權限檢查確認「你能做什麼、能看哪些資料」。子女不能查全家總覽
JWTJSON Web Token可驗簽的登入權杖；不是密碼，也不代表內容加密。Authorization: Bearer ...
Access / Refresh token存取／更新權杖前者用於API呼叫；後者用於換發新的存取權杖。refreshToken不應公開
Session工作階段一次裝置登入的狀態，可撤銷與到期。個人資料中的登入裝置
Scope資料範圍這次查詢要看哪個被允許的集合。me、family、userId、groupId
Audit log稽核紀錄記下重要操作的時間、操作者與事件供追溯。邀請、角色變更與監管事件

AI 與評測 Models and evaluation

English / 中文簡短解釋專題例子
NLP自然語言處理讓程式處理人平常說寫的語言。一段消費敘述拆成幾筆帳
LLM大型語言模型學習語言模式的模型，可抽取、判斷與生成文字；可能出錯。解析語意與撰寫財務敘述
Rules-based parsing規則解析依程式寫好的條件、字詞與格式處理輸入。找到早餐關鍵字與金額55
Prompt提示內容送給模型的任務說明、資料與範例。分類清單、缺欄位要留空
Zero-shot / Few-shot零樣本／少樣本提示不放示例／放少量示例；都不會修改模型權重。prompt裡放兩段記帳標準格式
Inference推論使用已有權重產生結果。呼叫chat completions
Fine-tuning微調用訓練資料更新模型或adapter參數。規劃中的記帳抽取訓練；本次未執行
LoRA / QLoRA低秩適應／量化低秩適應LoRA訓練較少的附加參數；QLoRA搭配量化基底以降低記憶體需求。規劃Qwen基底加記帳adapter
Adapter weights適配器權重微調產出的附加模型參數，通常需搭配正確基底。不是api.js的資料轉接器
Function / Tool calling函式／工具呼叫模型產生符合定義的工具參數，由程式驗證再執行。record_transactions屬規劃；工具名稱不代表已寫入DB
Confidence信心度對結果可靠性的分數或指標；未校準前不能當作真正機率。低信心欄位要求人检查
Hallucination幻覺／無依據生成產生輸入與事實不支持的內容。沒寫咖啡金額卻自行填60
Fallback備援主服務不可用時使用可識別的替代流程。模型503→規則；寫入仍走後端
Annotation / Gold label標註／標準答案由人工依固定規則寫出的可比較答案。人工指定金額、日期、收支、分類
Training / Validation / Held-out test set訓練／驗證／留出測試集學習參數／選方案／最後評估用的不同資料。留出集不得拿來反覆改prompt
Data leakage資料洩漏測試答案或近似樣本混入訓練或調參，使成績過度樂觀。同句換金額後落在訓練與測試兩邊
Exact match rate完全正確率指定欄位全部吻合的樣本比例；須說清楚以筆或整段計算。整段所有交易的四個核心欄位全對
Precision / Recall / F1精確率／召回率／F1預測有多少對／答案有多少找到／兩者的調和平均。餐飲分類的TP、FP、FN
Macro-F1各類別F1的平均先算每類F1再平均，各分類權重相同。避免常見的餐飲類掩蓋小分類失誤
Latency p50 / p95延遲第50／95百分位50%／95%的請求在該時間內完成，不是最大值。包含指定部署與網路下的模型等待
Baseline / Blind rating基準線／盲評作為比較的基本方法／評者不知道輸出來自哪個版本。規則基準；財務建議雙版本盲評

測試與部署 Testing and deployment

English / 中文簡短解釋專題例子
Unit / Integration / End-to-end test單元／整合／端到端測試測小函式／測元件交互／從使用者操作走完整流程。金額處理、API+DB、兩帳號完整demo
Negative test反向測試確認不被允許或非法的行為確實被拒絕。子女直接查全家summary
Stub / Skipped佔位實作／跳過stub是待完成程式；skipped是測試沒有執行，不能算通過。501路由、pytest skipped
Email verification信箱驗證用寄往信箱的限時單次連結證明收信能力。正式環境先驗證再登入；本機示範明示未寄信
IndexedDB / Blob瀏覽器資料庫／二進位物件在裝置保存原始圖片，不把大照片塞進文字偏好設定。登入背景照片與重新整理後恢復
Cover / Contain / Tile填滿／完整顯示／重複鋪排控制照片如何適應畫面；位置滑桿調整對齊或裁切。自己的登入背景
Manual entry / Actual debit手動記帳／實際扣款由人確認帳單金額，獨立於AI和參考試算。匯率帶入後可修改為銀行實扣
Exchange rate / Base currency匯率／基準幣別1單位來源貨幣能換得多少目標幣；比率需連同日期與來源。USD、TWD、JPY等153法定貨幣；帳本本位幣TWD
Decimal / Quote date / Stale十進位／行情日期／過期標示保留金額精度並區分資料更新日期和取得時間，過期行情不能假稱即時。日圓0位、美元2位、每日匯率明示來源日期
Health check健康檢查確認服務的指定狀態；不等同完整產品驗收。/healthz
Environment variable / Secret環境變數／機密在程式外設定運行值／應限制存取的敏感值。APP_ENV／JWT_SECRET、API key
Blueprint部署藍圖以設定檔描述服務與資料庫，套用後平台建立資源。Render讀render.yaml；檔案存在不代表部署完成
Persistence / Backup持久化／備份服務重啟後保留資料／另外保存可還原副本。PostgreSQL儲存；仍需驗證備份策略
